# Webdesign Pymes

Sitios demo para pymes locales (proyecto **Webs para Pymes**).

## Estructura
- `sites/<slug>/index.html` — un sitio por carpeta (estático, una página, sin dependencias).
- `vercel.json` — config de despliegue (`cleanUrls`).

## Despliegue
Vercel conectado a este repo (framework *Other* / estático). Cada `git push` a `main` despliega automáticamente.

## URL de cada sitio
`https://webdesign-pymes.vercel.app/sites/<slug>`
